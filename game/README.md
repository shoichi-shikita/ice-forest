# アイスの森 — Prototype v0.32
Godot 4.7.2 / Windows / Forward+（Vulkan）。原作を拡張する内部検証用の短い試作。完成目標60〜120分の本編は未完成です。

## 起動
「遊ぶ.cmd」をダブルクリック。このPCのGodotを使い、左のサブモニターで起動します。
予備の「互換描画で遊ぶ.cmd」は通常霧のみで起動します。Godot本体を移動した場合はproject.godotをインポートしてください。

## 操作
WASD 移動、マウス 視点、Shift 早歩き、F 懐中電灯、E 調査。棒に近づいて見下ろし、灯りを点けるとEが表示されます。
調査中はEまたはEscで戻ります。調査以外のEscは移動停止・カーソル解除。H 操作案内、V 揺れ切替、J 会話字幕、F3 開発情報。
最奥まで進み、入口へ戻ると試作終了。棒はすべて読む必要はありません。終了後Enterで再開始。

## v0.32の追加
- 棒の文字を中央字幕へ転記せず、照らされた木肌を低い視点で覗き込みます。棒は地面に残ります。消灯中は調査を開始できません。
- 教科書体などのシステムフォントを使い、字ごとの角度・位置・濃さをずらした縦書き。専用手書き画像は未制作。フォントファイルは同梱していません。
- 航・真帆・涼太の会話字幕。人物モデル・会話音声は未実装。Jで字幕を消すと会話は提示されません。
- 退色した赤い境界杭、轍の暗い帯、放置された黒いポリパイプを追加。
- 手前の領域から戻るだけでは終了せず、最奥到達後の帰還を必須に修正。

## 構成
main.tscn → scripts/game.gd：森林・灯り・調査・会話・進行・後処理。
scripts/player.gd：移動・身体性・遅延足音・覗き込みカメラ。
scripts/forestry_details.gd：杭・轍・パイプ。
shaders/night_post.gdshader：レンズ歪み・周辺減光・色収差・粒子。
MASTER_CONTEXT.md / DESIGN_RULES.md：制作基準。

音は合成した仮音源。長編構成、友人の声と姿、専用森林アセット、初見プレイ評価はこれからです。
