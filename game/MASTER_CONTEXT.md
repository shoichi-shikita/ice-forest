# アイスの森 — 制作マスター（2026-10-29）

原作を拡張する一人称心理ホラー。完成目標60〜120分。現在は短い垂直スライスであり、長編完成版ではない。

## 固定する基準
- プレイヤーに正解を教えず、見てしまったものを残す。
- 進捗カウンター・採点・主人公の状況解説モノローグを出さない。
- 安易な大音量やドアップではなく、不条理、記憶の食い違い、静寂を使う。
- 昭和〜平成に間伐・管理され、今は放置された日本の杉人工林。物品には持ち込まれた理由がある。
- Outlastは明暗・主観視点・レンズと身体感覚の参考。既存アセットを模倣・流用する指示ではない。
- 消灯時の暗黒、環境光0.02/月光0.03、固定露出、ライト中心と周囲の強い差、周辺減光・歪み・色収差・粒子、呼吸と歩幅同期を保つ。
- 原作由来の事実と独自追加は区別する。現状の会話・小道具・演出の追加はゲーム独自の試作。
- 全回収は不要。最奥z<-43到達後に入口z>4へ戻れば終了。
- 実装・実機検証・聴感/初見評価を分けて報告する。作業画面はサブモニターに限定。
