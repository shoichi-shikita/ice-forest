# 作品固有の制作基準

1. 土地・季節・生活痕跡の観察が先。異常はその後。
2. 棒はクエスト目標ではない。重要な棒を見逃しても世界は存在し続ける。
3. 大学生の会話は説明ではなく関係性を示す。無関係な話を許す。
4. 無根拠に怪異の設定を付け足さない。原話・独自追加・仮説の区分を維持する。
5. UIは操作補助とアクセシビリティに限定。恐怖をUIで説明しない。
6. 実験項目: 初見で何を覚えたか、棒の言葉をどう解釈したか、どこで迷ったか。
7. 生成文は声に出して読んで削る。説明的なら台詞を取る。
8. 「AIらしさ排除」は表面上の乱雑化ではなく、具体的な意図と場所固有の理由を与えること。

## 次の垂直スライスの受け入れ基準
- 森の入口→異物の発見→空気の変化→帰路の5〜10分が破綻なく成立。
- 安い大音量驚かしを使わない。
- 3名の初見テスターにプレイしてもらい、説明を足さずに探索できるか記録。
- 見た目は土着的な日本の植林地。現地の具体的資料を参考に構築する。
